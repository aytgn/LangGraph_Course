# Abonelik Takipçisi

Bu uygulama, abonelik giderlerinizi yönetmenizi sağlayan bir Streamlit arayüzüdür.

## Özellikler
- Abonelik ekleme, silme ve listeleme.
- Aylık ve yıllık toplam gider hesaplama.
- Kategori bazlı interaktif grafikler.
- Yaklaşan ödemelerin takibi.

## Kurulum
1. `pip install -r requirements.txt` komutunu çalıştırın.
2. `streamlit run app.py` ile uygulamayı başlatın.
